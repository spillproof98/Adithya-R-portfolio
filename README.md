# Adithya R — Portfolio (Vite + React + Tailwind)

This repo is a production-ready portfolio website scaffolded with Vite, React, Tailwind CSS and Framer Motion.
It includes your resume and screenshots for the four projects you provided.

## Quick start

1. Install dependencies:
```bash
npm install
```

2. Start dev server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## Deploy
- Deploy to **Netlify**: Connect repository, set build command `npm run build` and publish directory `dist`.
- Deploy to **Vercel**: `Import Project` -> it auto-detects Vite.
- Or use GitHub Pages with `gh-pages` (add scripts) if needed.

## Files included
- `public/AdithyaR_FSD2025.pdf` — your resume
- `public/*.png` — project screenshots copied from your uploads
- `src/` — React app source

## Customization
- Edit `src/App.jsx` and `src/components/ProjectCard.jsx` to tweak content or add new projects.
- Tailwind config: `tailwind.config.cjs` — accent color already set to purple `#7C3AED`.
